# Support

Before opening an issue:

1. Read the [user guide](docs/使用说明.md).
2. Check existing issues for the same symptom.
3. Retry with the latest published version and a small synthetic knowledge
   base when possible.

Use a GitHub issue for reproducible bugs and feature requests. Include the app
version, Windows version, steps to reproduce, expected behavior, and sanitized
diagnostics. Never attach a private knowledge base, personal notes, API keys,
local user paths, or credentials.

Security issues must follow [SECURITY.md](SECURITY.md).
