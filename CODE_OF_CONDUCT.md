# Code of Conduct

## Our standard

We want this project to be a welcoming place to learn and collaborate.
Contributors should be respectful, specific, patient, and constructive.

Unacceptable behavior includes harassment, discrimination, threats, deliberate
disclosure of private information, sexualized conduct, personal attacks, and
repeated disruption of project work.

## Scope

This standard applies in repository issues, pull requests, reviews, discussions,
and other spaces where someone is representing the project.

## Reporting and enforcement

Do not publish another person's private information while reporting a concern.
Use GitHub's abuse-reporting controls for urgent platform abuse. For a
repository-specific concern, request a private contact channel from the
maintainer without posting sensitive details publicly.

Maintainers may edit or remove content and may temporarily or permanently
restrict participation when behavior is inconsistent with this standard.
Enforcement decisions should consider context, impact, prior behavior, and the
safety of affected participants.
