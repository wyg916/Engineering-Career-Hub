# 工程经验求职学习中心 V1 使用说明

## 1. 安装和首次启动

1. 从 GitHub Releases 下载安装程序，对照 Release 说明或公开验收报告核对
   SHA256，再双击并按向导安装到当前用户目录；不需要管理员权限。
2. 从桌面或开始菜单打开“工程经验求职学习中心”。
3. 首次启动会自动读取 Codex 的 `experience-recorder.json`。如果没有发现知识库，点击“选择知识库”并选择包含 `01_原始经验卡片` 的知识库根目录。
4. 选择重点项目、技术方向、面试日期和每日学习时长；默认每天 20 分钟。
5. 完成引导后进入“今日学习”。

## 2. 推荐的日常学习流程

1. 在“今日学习”先完成到期复习，再学习最多 3 张推荐新卡。
2. 阅读卡片的“问题表现、根因、解决方案、验证、真正学到什么、快速定位、面试提炼”。长证据默认折叠，可按目录跳转。
3. 根据实际回忆情况选择“忘记、困难、掌握、轻松”。系统按当天、1、3、7、14、30 天的六级 Leitner 间隔安排下一次复习。
4. 对重要内容收藏或写个人笔记；这些信息只保存在应用数据中。
5. 临近面试时使用“面试训练”，隐藏答案后进行 30 秒或 2 分钟计时，再逐步揭示知识库中已有的回答与追问。

## 3. 各页面用途

- 今日学习：到期复习、新卡推荐、掌握度、连续学习和薄弱领域。
- 经验库：全文搜索，并按项目、领域、标签、验证状态、学习价值、面试价值、掌握状态和日期筛选。
- 项目专题：按真实来源项目查看经验脉络。
- 技术领域：按领域查看卡片数量和掌握情况。
- 面试训练：使用经验卡已有问题、30 秒回答、2 分钟结构和追问，不生成虚构内容。
- 学习进度：查看总体掌握、复习记录、连续学习和领域分布。
- 阶段复盘：浏览项目索引、候选面试案例、周报、阶段复盘和待学习知识。
- 设置：切换知识库、主题、字号、宽屏模式和每日计划，导入或导出学习数据。

## 4. 搜索和键盘操作

- 按 `/`：从任意页面进入经验库并聚焦搜索框。
- 按 `Esc`：关闭卡片或文档阅读层。
- 使用 `Tab` / `Shift+Tab`：在按钮、筛选器和输入框之间移动；按 `Enter` 或空格执行操作。
- 搜索支持中文、英文和混合关键词，例如 `TopN`、`权限`、`RAG`，命中词会高亮。

## 5. 学习数据与备份

学习状态位于：

```text
%APPDATA%\EngineeringExperienceStudyCenter\learning-state.v1.json
```

应用以临时文件原子替换主状态文件，并保留最近 5 份滚动备份。建议在“设置 → 学习数据”定期导出 JSON；迁移设备后可在同一位置导入。

学习状态包含收藏、个人笔记、掌握状态、信心等级、复习日期、学习记录和设置，不包含知识库原文副本。

## 6. 知识库更新和故障处理

- 外部新增、更新或删除经验卡后，应用会自动监听并刷新；也可点击右上角刷新按钮。
- 文档缺字段或 YAML 损坏时，其他内容仍可使用；问题会进入设置页的数据诊断列表。
- 知识库临时不可访问时，重新连接磁盘后到“设置”检查路径并手动刷新。
- 若 Windows 对未签名安装包显示“未知发布者”，请先核对 `docs/验收报告.md` 中的 SHA256。

## 7. 卸载

从 Windows“已安装的应用”卸载时，会询问是否删除学习数据：

- 选择保留：以后重装可继续原学习进度。
- 选择删除：只删除 `%APPDATA%\EngineeringExperienceStudyCenter\`。

两种选择都不会删除或修改个人工程经验知识库。
