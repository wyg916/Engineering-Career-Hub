## 安全与数据边界

- Electron 启用 contextIsolation、sandbox 和 webSecurity，关闭 nodeIntegration。
- 渲染进程不能直接访问文件系统，仅能调用预加载层暴露的窄 IPC。
- IPC 校验调用窗口、主 frame、参数类型、路径边界和允许的操作。
- 禁止 webview、任意导航、非 HTTP/HTTPS 外链和生产期网络请求。
- Markdown 使用严格白名单清洗，脚本、事件属性和危险链接不会执行。
- 学习状态只写当前用户的应用数据目录，不写知识库或业务仓库。
- 单实例锁避免两个窗口并发覆盖学习状态。

## 公开隐私处理

- 原真实知识库截图已移出公开目录并置于 Git 排除的本地私有目录。
- E2E 不再读取真实 experience-recorder.json，也不会默认生成真实截图。
- 原内部验收报告中的真实根路径、计数、哈希和用户目录未进入公开版本。
- 知识库哈希脚本要求调用者显式传入路径，不再包含个人默认路径。
- 应用图标 PNG 已重新编码，移除非必要编辑元数据；来源见
  asset-provenance.md。
